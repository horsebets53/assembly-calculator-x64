# Публичные коды доступа тестовой сессии

> **ВНИМАНИЕ:** эти действующие коды намеренно опубликованы по явному
> подтверждению владельца репозитория. Они больше не являются секретами.
> Пока соответствующие сервисы доступны, любой, кто знает адрес сервиса,
> может использовать эти коды. Веб-терминал предоставляет выполнение команд
> с правами пользователя песочницы, включая изменение и удаление файлов.

## Parcel64

Код доступа:

```text
e719bf0f
```

Сервер принимает его в заголовке `X-Upload-Code`.
Настройка при запуске: переменная окружения `UPLOAD_CODE`.

## Веб-терминал

Код доступа:

```text
86c573540fe52d8e557f36c9fa01d202
```

Сервер принимает его в заголовке `X-Terminal-Key`.
Настройка при запуске: переменная окружения `TERMINAL_ACCESS_KEY`.

## Область действия и отзыв

- Это коды конкретной тестовой сессии. Они были проверены на работающих
  сервисах перед публикацией, но могут перестать действовать позднее.
- Этот файл не загружается серверами автоматически и не меняет их настройки
  по умолчанию. Без соответствующей переменной окружения при запуске
  генерируется новый случайный код.
- Не используйте эти публичные значения для новых, приватных или
  производственных окружений.
- Чтобы отозвать доступ, остановите соответствующий сервер и запустите его
  с новым непубличным кодом. У веб-терминала предварительно завершите сессию.
- Удаление этого файла не отзывает коды: значения останутся в истории Git
  и могут быть сохранены другими людьми.
