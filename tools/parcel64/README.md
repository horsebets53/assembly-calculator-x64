# Parcel64

Временный загрузчик файлов в песочницу: **до 500 МиБ на файл**, части
**до 64 МиБ (67 108 864 байта)**. Самостоятельный инструмент, не участвует
в сборке ассемблерного калькулятора. Python 3.9+, сторонних пакетов нет.

## Запуск

```bash
python3 tools/parcel64/server.py
```

Сервер слушает `0.0.0.0:8080`. Код доступа выводится в терминал; введите его
на странице. Через Arena используйте HTTPS-превью, локально —
`http://localhost:8080`. За пределами доверенного компьютера нужен HTTPS-прокси:
встроенный HTTP-сервер сам TLS не предоставляет.

Переменные окружения:

- `PORT` — порт, по умолчанию `8080`.
- `UPLOAD_DIR` — каталог данных, по умолчанию `~/.cache/arena-uploads`.
  **Не указывайте отслеживаемый Git-каталог** для загрузок.
- `UPLOAD_CODE` — свой код доступа. Если не указан, генерируется случайный.
  Не добавляйте реальные коды в Git.

## Передача

1. Браузер создаёт сессию с именем и полным размером файла.
2. Отправляет последовательные `PUT` с телом до 64 МиБ и заголовком
   `X-Offset`. Последняя часть может быть меньше, выравнивание не требуется.
3. Сервер записывает данные потоково (буфер 64 КиБ) и подтверждает смещение.
4. При потере ответа браузер запрашивает подтверждённое смещение: уже
   принятую часть повторно не дописывает. До трёх автоматических повторов;
   ручной повтор продолжает существующую сессию, пока вкладка и сервер живы.
5. После полного получения файл переименовывается из `.part`, а рядом
   сохраняются метаданные и SHA-256. Это хеш **полученных байтов**; для
   проверки оригинала сравните его с независимо вычисленным локальным хешем.

Имена очищаются от путей и получают случайный префикс. Загрузки никогда не
запускаются и не распаковываются. Пустой файл завершается без `PUT`.

## Ограничения

Это инструмент для временной сессии, **не production-файлохранилище**.
Незавершённые сессии хранятся в памяти; восстановление после перезапуска
сервера или закрытия вкладки не реализовано. Завершённые файлы остаются на
диске до удаления, но их сохранность зависит от срока жизни среды.
Есть ограничение на восемь активных сессий и резерв свободного места на диске.
Не публикуйте код доступа и не отправляйте чувствительные данные в недоверенную среду.

Страница `/diagnostics` измеряет предел тела одного запроса через текущий
прокси: тестовые байты не сохраняются. Запуск только вручную, до 3 ГиБ
тестового трафика. Отчёт — `probe-report.json` в каталоге данных.
**Измеренный в этой сессии** предел: `104857600` байт принимается,
`104857601` получает HTTP 413. Это не универсальная гарантия для других
прокси или будущих настроек Arena. Загрузчик оставляет запас: 64 МиБ на запрос.

## Проверки

```bash
python3 tools/parcel64/test_server.py
# Необязательно, при наличии Node.js: логика клиента с моделируемой сетью
node tools/parcel64/test_client.cjs
```

Серверные тесты используют временный каталог и localhost. В том числе
передают полные 500 МиБ восьмью запросами (7 × 64 МиБ + 52 МиБ), сверяют
SHA-256, проверяют отказ для части больше лимита, неверное смещение,
отмену и восстановление после обрыва второй части. Требуется около 500 МиБ
свободного диска; тестовые данные удаляются. Это локальные тесты, не
повторное измерение внешнего прокси.
