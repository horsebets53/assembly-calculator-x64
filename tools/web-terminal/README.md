# Web terminal

Отдельный интерактивный Bash в той же песочнице, с веб-интерфейсом xterm.js.
Это **удалённый доступ к командной строке**, а не имитация терминала и не
дополнительная изоляция. Пользователь с кодом получает права пользователя
серверного процесса, включая доступ к его файлам и доступным ему средствам
повышения привилегий. Сетевые ограничения платформы не меняются.

## Запуск (Linux)

Нужны Python 3.9+, Bash, PTY и Node.js/npm для установки ресурсов интерфейса.
Сам сервер работает только на стандартной библиотеке Python.

```bash
cd tools/web-terminal
npm ci
python3 server.py
```

По умолчанию: `0.0.0.0:8081`, начальный каталог — корень репозитория.
Код доступа (случайные 128 бит) выводится в терминал при старте. Введите его
на странице превью. **Не публикуйте код и не коммитьте его в Git.**

Переменные окружения:

- `PORT` — порт, по умолчанию `8081`.
- `TERMINAL_CWD` — начальный рабочий каталог.
- `TERMINAL_ACCESS_KEY` — свой код; при отсутствии генерируется новый.

За пределами доверенного localhost используйте **только HTTPS-прокси**.
Сервер сам TLS не предоставляет. В Arena используйте HTTPS-превью.
Это временный инструмент для владельца песочницы, не production-сервис
и не многопользовательская система разграничения доступа.

## Поведение

- Shell создаётся после ввода кода и нажатия «Подключить».
- Одна общая Bash-сессия на экземпляр сервера, без прав root по умолчанию.
  Несколько клиентов с одним кодом видят и управляют **одной** сессией.
- Cwd, переменные и интерактивные программы сохраняются между командами.
  Это отдельный shell, не терминал, в котором агент уже выполняет команды.
- Ctrl+C прерывает текущую foreground-задачу. «Очистить экран» не
  останавливает команды и не удаляет вывод из серверного буфера.
- Ввод передаётся последовательными запросами без автоматических повторов,
  чтобы потеря ответа не привела к повторному выполнению команды.
- Вывод передаётся long polling по HTTP, без WebSocket; старые байты сверх
  буфера 2 МиБ отбрасываются с предупреждением. Это не полный журнал работы.
- Код временно хранится в `sessionStorage` вкладки, не в URL и не в Git.
  Сервер не пишет ввод, вывод или ключи запросов в HTTP-журнал.
- Закрытие вкладки не останавливает shell немедленно: без обращений к нему
  он закрывается через 30 минут. Для явной остановки — «Завершить сессию».
- При закрытии останавливаются процессы, ещё принадлежащие сессии Bash
  и доступные для завершения пользователю сервера. Отсоединённые через
  `setsid` или привилегированные процессы могут потребовать отдельной уборки.
- История Bash в файл не записывается. Файлы, изменённые командами,
  остаются изменёнными. Не редактируйте те же файлы одновременно с агентом.

## Проверки

```bash
python3 tools/web-terminal/test_server.py
node --check tools/web-terminal/terminal.js
```

Тесты поднимают локальный HTTP-сервер и настоящий PTY, проверяют отказ без
кода, ввод/вывод, изменение каталога, размер терминала, Ctrl+C и закрытие
сессии. Рабочий каталог тестовой оболочки временный и удаляется после теста.
